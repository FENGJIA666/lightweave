# Learn AR with SPECS：创意方向与最终选题

主 Manager 已选定 **LightWeave**。正式制作与文案以本节及 `docs/presentation/` 为准；后面的三个方向保留为创意比较记录。

## 最终选题：LightWeave

**Shape the light. Watch your world bloom.**

设计目标是用单手 pinch/drag 旋转同一面空间镜子，让可见光束沿反射路径依次点亮三个花苞。不同高度的目标引导使用者从不同视角观察光路，每一次点亮都有明确的绽放反馈，完成后可重置再玩。核心表达为 **One mirror. Three discoveries.**，面向充满好奇的学习者与第一次体验空间解谜的玩家，让镜面角度、光路与目标反馈之间的联系直接可见。

画面采用发光金线、亮色花苞和清晰轮廓；环境来自实际 Lens Studio Preview。SPECS 使用 additive display，黑色呈透明，不以深色背景承载画面对比。对外叙事把「旋转—连接—绽放」作为主线，展示完整可验证的成功过程。

正式视频以 150 秒为制作目标，覆盖 start、三个 bloom 与 reset。对外文字的完成式表述须由真实实现与对应 Preview 镜头支持；待录制状态单独记录在制作文件中。

## 前期创意比较记录

以下三个早期提案曾用于评估空间交互、用户价值和叙事清晰度。正式方案现已收敛为 LightWeave。

## 方向一：Vector Voyage

**故事钩子：Turn every step into a mathematical discovery.**

把向量从纸面上的箭头变成学习者可以走过的路径。设计目标是让学习者在身边放置两段位移箭头，观察首尾相接后的合位移，并完成一次「抵达目标」的空间挑战。

**用户价值。** 以自己站的位置、移动方向和可见终点理解向量相加。一次任务围绕一个清楚的问题展开：两次移动，如何连接同一个起点与终点？

**AR 的关键作用。** 箭头与真实空间中的位置对应，学习者能够绕到侧面观察方向、沿路径移动，并从第一视角看到分段路径与合位移的关系。身体位置成为理解概念的一部分。

**拟定关键交互。** 设置起点 → 用可支持的输入方式放置两段箭头 → 显示合位移 → 调整其中一段以抵达目标 → 展示任务完成反馈。实现时优先选择目标平台原生支持、容易清楚录制的输入方式。

**三分钟内的视频故事。**

| 时间预算 | 画面与叙事目标 |
| --- | --- |
| 0:00–0:15 | 真实空间中出现明亮箭头，学习者迈出第一步；直接呈现作品名称和钩子。 |
| 0:15–0:40 | 给出第一个目标点，展示完整交互入口。 |
| 0:40–1:30 | 连续演示放置两段向量与合位移出现，保留可理解的操作节奏。 |
| 1:30–2:10 | 调整方向，完成抵达目标挑战，清楚显示成功结果。 |
| 2:10–2:40 | 用画面回扣数学关系和空间交互的意义，展示实际使用的制作技术。 |
| 2:40–2:55 | 重现最有表现力的一刻，以 “Move. Connect. Discover.” 收束。 |

**预期亮点。** 一个概念、一条完整挑战、一个鲜明成功瞬间；适合把数学解释、空间交互和动态画面紧密结合。

## 方向二：Orbit Playground

**故事钩子：Hold a solar system in your room. Discover what keeps it moving.**

将轨道学习设计成一个围绕学习者展开的微型天体实验室。设计目标是让学习者设置中心天体与一个运动天体，通过一个明确参数观察轨迹变化，完成一次「找到目标轨道」的挑战。具体模型与参数在实现时固定，并让画面与模型一致。

**用户价值。** 将运动路径和空间关系变成可观察、可比较的现象。学习者通过一次改变和一次观察，建立参数与轨迹之间的联系。

**AR 的关键作用。** 学习者可以从上方、侧面和近处观察同一条三维轨迹，借助真实房间建立尺度和方向感；轨道在周围空间中持续可见。

**拟定关键交互。** 放置中心 → 创建运动天体 → 调整一个轨道参数 → 从另一角度查看轨迹 → 达成明确的目标状态。用简洁标签说明当前模型中的物理量，确保视觉叙事与教学内容相符。

**三分钟内的视频故事。** 前十五秒用环绕轨迹建立视觉记忆；接下来三十秒展示参数与任务；用九十秒完成一次参数变化和目标轨道挑战；用四十秒解释学习收获及实现亮点；最后十五秒回到最吸引人的空间轨道画面。

**预期亮点。** 强烈的三维视觉表现与可重复的因果实验，形成 “Change one thing. See a new world of motion.” 的叙事核心。

## 方向三：Field Finder

**故事钩子：Step into an invisible field. Make its patterns appear.**

把电场教学转化为探索看不见的空间规律。设计目标是让学习者在空间中放置两个电荷，用一个虚拟探针探索不同位置的场方向与相对强度，最后找到一个满足任务条件的位置。教学模型、数值范围与图形映射在实现时明确固定。

**用户价值。** 把「某一点的场」变成可以主动寻找的结果。通过移动探针和比较箭头，学习者建立位置、方向与强度之间的联系。

**AR 的关键作用。** 探针与场箭头处于同一真实空间参照系；学习者绕行、靠近、退后，从不同位置看到同一规律。空间中的观察位置直接决定当前显示的学习内容。

**拟定关键交互。** 放置电荷 → 移动探针 → 即时显示方向与强度 → 寻找指定区域 → 完成探索挑战。以一种电荷配置和一个任务保证故事清晰完整。

**三分钟内的视频故事。** 前十五秒让空中场线随探针出现；三十秒介绍探索目标；九十秒展示三个有区别的位置并完成一次寻找任务；四十秒把空间反馈与学习概念连接；十五秒以 “Explore the space. Reveal the pattern.” 收束。

**预期亮点。** 把不可见概念变成围绕身体展开的探索活动，形成具有辨识度的「移动—发现—完成」体验。

## 早期初选记录

早期建议优先评估 **Vector Voyage**，其学习目标和成功瞬间容易清楚表达。随后结合官方四项等权评分、Design 平分优先规则与主管提出的可实现空间光路方案，最终选择了 **LightWeave**。

后续正式材料以实际完成的作品为准：项目介绍、视频口播、字幕和成果描述保持同一个名称、同一个任务、同一组可验证的亮点。
