# LightWeave：中文审核版

**编织光路，让世界绽放。**

一句话定位：旋转一面镜子，让金色光束穿过三维空间，点亮三朵发光花卉，完成一场有鲜明成果反馈的 AR 挑战。

## 参赛文章

### 为谁而设计

LightWeave 面向充满好奇的学习者，以及第一次体验空间解谜的玩家。

它的邀请简单而直接：改变镜面角度，看着光路移动，找到让目标绽放的那一次连接。

### 灵感

一道光，可以把一个小小的动作变成美丽的发现。

LightWeave 让这种联系清楚可见：转动镜面，追随新的光路，看着花朵在光束抵达时绽放。

一面镜子，三次发现。

### 作品体验

LightWeave 把一道发光谜题放进你身边的空间。

通过单手捏合与拖动旋转镜面，改变光束方向。

四个精调按钮分别以两度为一步调整偏航或俯仰角。

沿着金色光路，探索位于三个不同高度的珊瑚色、青绿色与金色目标。

每个新抵达的目标都会绽放成一朵八瓣花；明亮的花心与脉动的边缘，则显示光束当前抵达的位置。

引导光束探索下一个目标时，已获得的花朵保持绽放。

点亮三朵花，完成整座光之花园；选择 Replay，即可再次创造光路。

### AR 的魅力

这道谜题在三维空间中展开。

改变观察角度，探索镜面、光束和高处目标之间的关系。

它们之间的空间也成为挑战的一部分。

下一次发现，从一个新的角度开始。

### 制作方式

我们首先使用 Devpost Learn 规划技能，明确核心空间体验、交互流程与具体完成标准。

随后使用 CLAD 的 Lens Studio 技能与原生 Lens Studio MCP 工具，在 Lens Studio 5.23.2 中搭建并检查场景。

TypeScript 光学核心计算光线与有限大小镜面的相交，根据镜面当前朝向计算反射，并检测光线是否抵达接收目标。

返回的几何结果驱动可见光束，只有光路真正命中目标，才获得对应的花朵。

Spectacles Interaction Kit 将捏合拖动输入连接到镜面旋转，UIKit 则提供四个角度精调按钮和 Replay。

我们为花朵、镜面、光源与光束制作了原创的切面风格模型，并让每朵花的花瓣与高光同步展开。

六段原创合成音频分别承载交互、单朵花绽放、完成庆祝与环境氛围。

### 设计命题

我们的核心设计命题，是让每一次反射都清晰可见，让每一次成功都令人愉悦。

金色光束呈现路径，明亮的目标指引方向，绽放的花瓣庆祝每一次连接。

镜面高亮响应悬停与选中；接收光束的花朵通过明亮花心与脉动边缘，清楚呈现当前命中状态。

不同的目标高度，让玩家从多个视角理解谜题的空间结构。

### 作品成果

我们把直接镜面交互、实时计算的光路、三朵动态花卉和 Replay 整合在同一个 Lens 中。

一段连续的原生 Lens Studio Preview 录制完整呈现两轮三花挑战，并记录了两轮之间 Replay 恢复初始状态的过程。

独立光学核心通过了 40 项数值与状态测试，覆盖反射、相交、目标可达性、进度与重置。

五个 Lens Studio Preview 自动化 LEAF 场景全部通过，覆盖初始控制、连续拖动与状态保持、目标连接与提示音事件、多轮 Replay，以及待播放完成提示的取消。

[验证报告](../validation.md)汇集了这些结果、连续录像，以及向左右各移动 25 厘米的实际玩家视角。

最终呈现的是一段完整旅程：从第一次转动镜面，到整座花园绽放。

### 创作收获

围绕一个清晰动作展开设计，让整个体验紧密相连。

同一次镜面移动，既塑造光路，也推动挑战，并带来可见的奖励。

### 下一步创意

下一步，我们希望创作一组各具特色的光之花园，赋予每座花园独特的空间布局、配色与探索路径。

LightWeave 从一道金色光束开始，以一个绽放的世界收束。
